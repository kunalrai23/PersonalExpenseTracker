# Personal Expense Tracker

A responsive web application for managing personal expenses and keeping track of spending.

## Features

- Add, edit, and delete expense entries
- Organize expenses by category
- Automatically calculate and display expense totals
- Save expense data in the browser using LocalStorage
- Responsive user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- DOM Manipulation
- Browser LocalStorage

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/kunalrai23/PersonalExpenseTracker.git
   ```

2. Open the project folder.
3. Open `index.html` in your web browser.

No additional installation is required.
